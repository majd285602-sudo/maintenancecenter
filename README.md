# Maintenance Center - C# OOP Project

نظام لإدارة مركز صيانة الأجهزة المنزلية بلغة C#.

## المفاهيم المستخدمة
- Encapsulation
- Inheritance
- Polymorphism - abstract method CalculateRepairCost
- Interface IRepairable
- Static members - TotalDevices, TotalValue
- Delegate & Event - StatusHandler
- Exception Handling
- List<Device>

## الأجهزة
- Refrigerator
- WashingMachine
- AirConditioner
